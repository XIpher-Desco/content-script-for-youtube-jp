# YouTube 日本語字幕ソーター (YouTube Japanese Subtitle Sorter)

YouTubeの字幕選択メニューで「日本語」を常に一番上に表示するためのChrome拡張機能です。

## 概要

YouTubeで動画を視聴する際、多くの言語の字幕が利用可能な場合、目的の「日本語」字幕を見つけるのが大変なことがあります。この拡張機能は、字幕メニューが開かれると自動的に「日本語」の項目をリストの最上部に移動させることで、その手間を省きます。

## 主な機能

- YouTubeの字幕選択メニューを開いた際に、「日本語」をリストの一番上に移動させます。
- パフォーマンスに配慮し、必要な時だけ動作するように設計されています。

## 導入方法

### 1. ファイルの準備
下記2つのファイル（`manifest.json`, `content.js`）をPC上の任意の新しいフォルダ（例: `my_youtube_ext`）に保存します。

- `manifest.json`
- `content.js`

### 2. Chromeへのインストール
1.  Chromeブラウザを開き、アドレスバーに `chrome://extensions` と入力して拡張機能管理ページに移動します。

2.  ページの右上にある「**デベロッパー モード**」のスイッチをオンにします。

3.  左上に表示される「**パッケージ化されていない拡張機能を読み込む**」ボタンをクリックします。

4.  先ほどファイルを作成したフォルダ（例: `my_youtube_ext`）を選択します。

5.  「YouTube 日本語字幕ソーター」が拡張機能のリストに追加されれば、インストールは完了です。

### 3. 動作確認
YouTubeのページをリロード（または新しく開いて）、字幕が利用可能な動画で字幕メニューを開き、「日本語」が一番上に表示されることを確認してください。

## ファイル構成

- `manifest.json`: 拡張機能の基本的な情報（名前、バージョン、実行するスクリプトなど）を定義するファイルです。
- `content.js`: YouTubeのページで実際に動作し、字幕メニューを並べ替えるJavaScriptコードです。
